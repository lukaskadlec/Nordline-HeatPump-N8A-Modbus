1. ARCHITECTURE & SYNCHRONIZATION OVERVIEW
================================================================================
The heat pump main controller (PC8002 PCB) synchronizes configuration settings with 
the LCD display (Slave 1) using 3 contiguous 90-register data blocks (270 registers 
total, registers 1001 to 1270):

- Block 1: Registers 1001 to 1090 (0x03E9 - 0x0442) -> 90 Regs / 180 Bytes
           Contains: System Settings (H), Protection Settings (A), Fan Settings (F)
- Block 2: Registers 1091 to 1180 (0x0443 - 0x049C) -> 90 Regs / 180 Bytes
           Contains: Defrost Settings (D), EEV Settings (E), Disinfection (G), Pump (P)
- Block 3: Registers 1181 to 1270 (0x049D - 0x04F6) -> 90 Regs / 180 Bytes
           Contains: Temperature Setpoints & Compensation (R), Timer Schedules

When the LCD controller powers on or issues a full resync (Flag 128 / 0x8000 in
Register 3011), the Master sends three consecutive Modbus FC 16 (0x10) frames
followed by a 1-register write to Reg 3011 to acknowledge and clear the flag.

Modbus Packet Structure (FC 16):
- Byte 0    : Slave ID = 1
- Byte 1    : Function Code = 16 (0x10)
- Bytes 2-3 : Start Register (Big-Endian)
- Bytes 4-5 : Register Count = 90 (0x005A)
- Byte 6    : Data Byte Count = 180 (0xB4)
- Bytes 7.. : 180 bytes payload (90 16-bit Big-Endian words)
- Last 2    : Modbus CRC-16 (Low byte, High byte)

Start Address Confirmation Registers:
- Reg 1010  : Value 1001 (0x03E9) -> Start address of Block 1
- Reg 1100  : Value 1091 (0x0443) -> Start address of Block 2
- Reg 1190  : Value 1181 (0x049D) -> Start address of Block 3

2.1 HOME ASSISTANT MQTT DISCOVERY NAMING & SORTING TAXONOMY
--------------------------------------------------------------------------------
To ensure logical grouping and alphabetical sorting on Home Assistant device cards,
all 109 configuration registers and 41 status/telemetry sensors follow a structured
taxonomy:

1. Primary Controls (21 user-facing control entities in HA "Controls" card):
   Clean display names without bracket tags:
   - Power State (switch.hp_power_state)
   - Operating Mode (select.hp_operating_mode)
   - Heating Setpoint (number.hp_heating_setpoint)
   - Hot Water Setpoint (number.hp_hot_water_setpoint)
   - Cooling Setpoint (number.hp_cooling_setpoint)
   - Timer 1 (ON) Enable / Time (switch.hp_timer_1_on_enable, time.hp_timer_1_time [Reg 1256 + 1259])
   - Timer 2 (OFF) Enable / Time (switch.hp_timer_2_off_enable, time.hp_timer_2_time [Reg 1258 + 1260])
   - Fast Mute (8h) (switch.hp_fast_mute)
   - Mute Timer Enable / Start / End (switch.hp_mute_timer_enable, time.hp_mute_start_time [Reg 1069 + 1261], time.hp_mute_end_time [Reg 1070 + 1262])
   - Electric Heater (switch.hp_electric_heater)
   - Pump Running Mode / Interval / Duration (select.hp_pump_running_mode, etc.)

2. Advanced Configuration (88 registers in HA "Configuration" card):
   Format: "[Group] Sub - ID Name"
   - [System]  : General, Network, Unit, Valve, Inverter, Model
   - [Protect] : Antifreeze, Limits, Valve
   - [Fan]     : Heating, Cooling, Manual, Mute, Motor
   - [Defrost] : Exit, Cycle, Sliding, Heater, Comp
   - [EEV]     : Mode, Heat, Initial, Defrost, Cool, Timing, PID, Manual
   - [Disinf]  : Target, Schedule
   - [Pump]    : Timing, Manual
   - [Temp]    : Diff, Limit, Heater, Curve
   Entity IDs (object_id): hp_<slug> (e.g. number.hp_temp_curve_r17_compensation_on_low_at)

3. Status & Telemetry Sensors (42 entities in HA "Sensors" and "Diagnostic" cards):
   Format: "[Group] Sub - Name / ID"
   - [Temp]       : Water (Inlet, Outlet, Boiler), Refrig (Suction, Discharge, Evaporator, Superheat), System (Ambient, Inverter, Module Protection)
   - [Pressure]   : Refrig (Suction Pressure, Discharge Pressure)
   - [Electrical] : AC (Voltage, Current), DC (Bus Voltage), Comp (Compressor Current)
   - [Fan]        : Motor (Speed, Speed Set)
   - [EEV]        : Valve (Steps)
   - [System]     : Status (Freq Set, Freq Actual, Power ON/OFF, Status)
   - [Output]     : Digital Relays (1) .. (13)
   - [Alarm]      : Diagnostic & Safety S01 .. S07, Detail (Code)

6. OPERATIONAL CONTROL LOGIC & SAFETY THRESHOLDS (FROM MANUAL)
================================================================================

6.1 Antifreeze Protection (Parameters A01..A04):
- Cooling Mode: After compressor start, outlet water temp T02 is monitored.
  If T02 < A01 (default 5.0 °C) OR suction pressure < A02 (default 2.0 bar) for 10s,
  unit enters antifreeze protection (after compressor has run 5 minutes).
- Heating / Hot Water Mode: If T02 < T01 - 2.0 °C AND T02 < A01 (5.0 °C), unit
  enters antifreeze protection.
- Protection Action: Unit stops compressor, 4-way valve remains unchanged, water pump
  KEEPS RUNNING.
- Automatic Reset: When T02 > A01 + A03 (default 5.0 + 2.0 = 7.0 °C) OR suction pressure
  recovers to >= A02.
- Manual Lockout: If antifreeze protection trips > 3 times within 30 minutes, automatic
  restart is inhibited (requires manual service reset).
- Low Ambient Temperature Lockout (A04): If ambient temp T07 < A04 (default -20.0 °C), unit
  will not start heat pump compressor. (Does not inhibit auxiliary electric heater; if
  heater runs, pump must run). Resumes when T07 > A04 + 2.0 °C.

6.2 Defrosting Control Logic (Parameters D01..D11):
- Defrost Initiation:
  1. Monitored 1 minute after compressor starts. If suction pressure < D05 (sliding low
     pressure threshold, default 5.3 bar / -12 °C), timed defrost countdown begins.
  2. If pressure sensor is faulty, timed defrost cycle D03 (default 45 min) with duration
     D04 (default 8 min) is automatically used.
- Defrost Sequence:
  (A) Compressor slows down to 30 Hz.
  (B) At 55s, fan motor stops and 4-way valve reverses direction.
  (C) At 60s (+5s), compressor ramps up to defrost frequency D11 (default 70 Hz).
  (D) If D10 = 1, electric heater is forced ON during defrost.
- Defrost Termination:
  Normal exit when discharge pressure T09 > D02 (default 25 bar / 41 °C) AND coil temp
  T06 > D01 (default 13.0 °C), OR when maximum defrost time D04 (default 8 min) elapses.
  Unit then drops to 30 Hz, reverses 4-way valve, restarts fan after 55s, and ramps up.

6.3 Electronic Expansion Valve Control (Parameters E01..E20):
- Compressor Start: EEV maintains initial position for the first 3 minutes.
  Initial heating steps = E05 (default 350 N) if ambient T07 >= 0 °C, or E05 + 50 N if T07 < 0 °C.
- After 3 minutes, automatic PID regulation takes over targeting superheat E02 (default 5.0 °C)
  and cooling superheat E11 (default 6.0 °C).
- Unit Shutdown: EEV opens to 480 steps for 2 minutes, then completely closes to 0 steps.
- Post-Defrost: EEV returns to initial position for 3 minutes before superheat PID re-engages.

6.4 Circulation Water Pump Staging (Parameters P01..P05):
- Lead & Overrun Timing: Pump starts at least P04 (default 1 min) before the compressor starts,
  and continues running for 2 minutes after the compressor stops.
- Flow Switch Guard: Controller begins monitoring water flow switch S03 after P04 - 10s.
  Once flow switch is closed continuously for 10s, compressor is permitted to start.
- Running Modes (P01):
  * 0 = Ordinary (Continuous pump run)
  * 1 = Special (Linked with compressor + overrun)
  * 2 = Interval (Cycle interval P02 with run duration P03)

6.5 Weather Compensation Heating Curves (Parameters R17..R22):
- Low Ambient Temp Curve:
  * R17 = Compensation-ON Low AT (Default 0.0 °C or -30.0 °C)
  * R18 = Compensation-OFF Low AT (Default -30.0 °C)
  * R19 = Max Compensation Target Temperature at Low AT (Default 45.0 °C)
- High Ambient Temp Curve:
  * R20 = Compensation-ON High AT (Default 55.0 °C)
  * R21 = Compensation-OFF High AT (Default 55.0 °C)
  * R22 = Max Compensation Target Temperature at High AT (Default 45.0 °C)

8. COMPREHENSIVE FAULT & ALARM CODE MATRIX (MANUAL SPECIFICATION)
================================================================================
When a safety protection trips or a component enters a fault state, the heat pump
main controller registers an alarm. The alarm is displayed on the physical LCD display,
logged in failure history ("Failure Logging" screen, access code 066 / 022),
broadcast via telemetry (Register 2085 and Register 2034 bitfield), and triggers
the general alarm output relay RO11 (Register 2019 Bit 10).
